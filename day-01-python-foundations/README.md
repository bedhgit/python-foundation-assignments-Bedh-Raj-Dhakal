# Day 01 — Python Foundations

Exercises covering variables, f-strings, conditionals, string cleaning,
ternary expressions, and membership checks.

| File | Description |
|---|---|
| `exercise-01-sales-summary.py` | Calculates gross sales, discount, and final sales for a product. |
| `exercise-02-data-quality-checker.py` | Computes problematic row percentage and classifies dataset quality. |
| `exercise-03-file-validator.py` | Validates a user-entered file name against allowed extensions (case-insensitive). |
| `exercise-04-customer-cleaner.py` | Cleans raw customer data (name, city, age, email) and determines adult status. |
| `exercise-05-pipeline-health.py` | Calculates pipeline failure rate and classifies health status based on failure rate and runtime. |
| `stretch-access-decision.py` | Determines dataset access based on user status, role, and dataset restrictions, printing a specific denial reason. |

## How to run

```bash
python3 exercise-01-sales-summary.py
```

(Exercise 3 will prompt for input in the terminal.)
